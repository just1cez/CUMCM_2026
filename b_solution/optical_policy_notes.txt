optical_policy_candidate 设计笔记

API
---
certified_optical_cover(poly, radius=19.9) -> list[Point] 与 geometry.optical_cover 同形。仅消费传入凸多边形顶点；不读取测量状态，不执行 I/O，不使用随机数。空集抛 ValueError；有限点、退化线和重复顶点可处理。候选若不能严格证书化，返回旧 optical_cover 的结果作为安全回退。

全域证书
--------
取输入顶点最远对作为纵向轴，并把所有顶点变换到该轴的精确 Fraction 坐标。将轴向包络区间分成有限个闭条带。每条带的上下界由落入条带的顶点和凸多边形边与两条带界面的精确线性插值得到；因此条带内多边形是一个包含于矩形 [left,right] x [bottom,top] 的集合。每个矩形再沿横向分成若干闭小矩形。对每个小矩形返回中心。

设小矩形半宽为 w、半高为 h，且 w²+h² <= radius²，则其四角（凸函数的最大值在矩形顶点取得）及其内部均在半径 radius 圆内。代码用安全半径 radius - 8*guard 选条带宽度，并用精确有理数逐角检查“实际返回的二进制浮点中心”到四角的距离；任一角不通过就放弃该完整候选。故不是顶点/边界抽样，而是整个凸域的覆盖证书。条带首尾采用蛇形顺序，适合调用方按序尝试。

浮点安全余量
------------
guard=max(1e-9,64 ulp(max(1,scale)))，轴向与正交向量先按浮点值转 Fraction，显式使用其实际范数平方；所有交点、分割和角点距离在 Fraction 中计算。8 guard 的半径余量覆盖坐标变换、min/max 和中心舍入的累积量；最终逐角精确检验仍是必要门槛。若半径余量不足、非有限中间量或任何条带无界面交点，直接保守回退旧 cover。

去重与失败盘
------------
对一个尚未清除、已知存在的频道，accepted=true且clear_result=no_target_in_range确实排除了以该清除点为中心、半径20米的闭盘；这与no_signal不同，且与定向源朝向无关。但只判断新清除中心位于旧失败盘内，不能推出新盘所负责的整块区域已经排除。实现不维护盘差产生的非凸集合，因此不据中心重叠删除覆盖义务，仅通过有证书的条带分割减少点数。Main仍保留整个可行域的后备覆盖，并在收到success后结束该频道。

局限与 Main 样例
----------------
候选只接受凸多边形；它不声称全局最少圆数，也不保证相对旧 cover 的实际移动严格下降（入口位置会影响首点；代码只接受不增加循环长度且减少固定尝试/clear 成本的候选）。Main 应至少打印旧/新点数、循环距离和从当前入口点的首点距离，不把未运行的结果写成收益。困难样例建议：长窄六角形（长度约 1100、宽度约 32，含轻微斜边）、三角格交叠后形成的 18 个圆外点凸包、以及接近退化的线段/点。预期度量是 optical clear 尝试次数、候选循环移动距离、首点距离和证书回退率；这些必须由 Main 在公开动作循环中实际统计。候选不得替代全清证书，也不得据“已发现频道”提前停止。
