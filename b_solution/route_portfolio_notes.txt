用途与证据边界
================
route_portfolio.py 仅依据调用者给出的当前位置、锚点坐标、已知目标中心和半径，返回 ("target", key) 或 ("anchor", key)。它不读取隐藏源真值、环境对象、历史轨迹或官方服务，不执行动作，不改变coverage证书/已访问集合/频道状态，不删除发现义务。没有I/O、随机数或第三方依赖。

接口
====
choose_portfolio_task(position, anchors, targets, risk_weight=1.0)
Point 为有限二维坐标；anchors 为 int -> Point；targets 为 int -> (Point, 非负有限半径)。两个字典不能同时为空。risk_weight 须有限非负；0 对应旧 center 目标，1 对应旧 guarded 默认。目标key和锚点key可相同，因为任务类型区分它们。输入字典及其中坐标均不修改。

内部目标
========
对全部 n 个任务的开放排列 π：
C(π) = d(position, π[0]) + Σ(i=0..n-2) d(π[i], π[i+1]) + p(π[0])，
p(target)=risk_weight*radius，p(anchor)=0。
不加回起点的边；只对首任务收半径惩罚。目标中心只是排序代理，不能据此直接clear。实际执行必须仍由现有认证定位器完成，每个任务执行后用新的公开摘要重新规划。

组合方式
========
1. 控制排列逐步复用 joint_dispatch_candidate.choose_task 的 nearest insertion + 最多 n 次首改进2-opt：同一编号、首点规则、nearest更新、插入算式、扫描顺序、容差和接受次数上限。没有修改或调用旧文件，也没有偷偷换掉历史控制策略。
2. 全局 cheapest insertion：每一步联合比较所有剩余任务和所有开放插入缝的增量，区别于控制算法先选距离当前路线最近的任务、再找插入缝。
3. 最多两个 nearest-neighbor 种子：首点取 origin距离+首点惩罚 最小的两个不同任务，之后按与当前末点距离追加。没有随机重启或海量种子。
4. 每个不同的完整种子最多 min(n,12) 轮；每轮同时扫描所有开放2-opt反转和单节点relocate/Or-opt1，在增量低于 -1e-12*max(1,C) 的动作中选最优。首点变化时计入半径惩罚，尾端没有虚构回程。每轮最多接受一个动作；接受前重新用math.fsum计算完整C，仅当严格减少才接受；浮点增量与完整成本不一致则停止该种子，不强行接受。
5. 初始最优解保留原控制排列；只有完整C严格更低的候选才能取代它。返回前还保留与控制C的显式比较。故对通过输入检查的同一输入，选中的内部完整排列的计算代理C不劣于旧算法的内部排列（同risk_weight）。此性质不是首个动作的距离保证。

确定性、任务守恒和数值边界
==========================
编号为target升序key，随后anchor升序key。控制内部保留旧tie；全局插入以(增量,编号,缝位置)打破tie；最近邻按(距离,编号)；局部搜索先按左/右索引扫描反转，再按节点/缝索引扫描relocate，同增量保留先扫描者；候选同C保留较早者，控制最早。不是承诺所有等距输入都直接返回编号最小的任务：旧插入规则本身允许前插。

插入每次从remaining移走恰好一个任务；反转是排列，relocate是pop一次再insert一次，所以重合坐标的多个任务仍各出现一次。relocate使用原排列的缝编号；节点左右相邻两缝跳过，其余缝端点不受删除影响；删除后处于原节点右侧的缝索引减1。由此包括移首、移尾和首尾互换，且无需每个候选拷贝完整排列。

空任务、非二维/非有限坐标、负数或非有限半径/风险权重、加权半径或距离溢出均报ValueError，不默默丢任务或返回假任务。另检查 max(origin)+max(penalty)+Σ max(edge-row) 的有限性：它是任意完整路线C的保守上界，宁可拒绝接近浮点极限的几何，而不拿无穷proxy排序。接口假定输入具有上述类型；不为任意畸形Python对象增加兼容层。实际比赛坐标远离浮点极限。math.fsum使最终候选比较不依赖求和顺序；旧控制的构造和局部接受算式保持原样。

CPU/空间上界（不是性能实测）
===========================
只建立一份n*n对称距离matrix；共 n+n(n-1)/2 次math.dist，所有种子和改进共享。内存 O(n^2)，最多4条种子、有限的候选副本和去重索引共 O(n)。不缓存所有候选排列。

控制2-opt最多 n*n(n-1)/2 个边界动作检查；全局插入恰有 n(n-1)(n+4)/6 次节点/缝检查；两条最近邻至多 n(n-1) 次余点距离比较。每个局部搜索轮最多 n(n-1)/2 次反转和 n(n-1) 次有效relocate，共 3n(n-1)/2 次O(1)距离表增量计算；全部候选至多4*min(n,12)轮，每轮至多一次O(n)完整proxy复算/拷贝。控制nearest-insertion另有O(n^2)插入、最近距离和选点操作。故时间O(n^3)，没有“直到收敛”的无界while（构造循环每次严格减少remaining）。

n=41时，距离计算861次、matrix1681项；全局插入12300次；控制反转至多33620次；组合改进至多48轮、118080次邻域动作检查。上述是明确计数上界，不是毫秒耗时预测，不保证达到局部或全局最优。n>41仍按同一有界算法工作，无隐式丢弃任务或降级。

不保证实际T下降
===============
C假设目标中心固定且每个任务只走一次；真实目标需要测向、清除、光学后备，定位结束位置未必在中心；任务会随新反馈变化，重规划也不承诺兑现当前完整排列。降低C可能仍增加第一跳，甚至实际L、M、S、F或总T。尤其长锚跳转可能被整体排列代理偏好，必须观察执行结果，不能据此宣布官方收益。该portfolio只改善排序搜索，没有新增探测/负证据推断。历史10700结果及refined名字不能直接归到本模块。

Main集中应核验的边界（本子任务未运行验证）
===========================================
A. 控制等价：在risk_weight=0、1及其他非负值，把 _control_route 的首任务与旧choose_task比较；center须以risk_weight=0传入。读取内部路由时独立重算C，逐例检查最终候选C<=控制C；不要以返回首任务猜测完整代理保证。
B. 长锚跳转：锚点沿宽大环/两簇排布，当前位置附近多个已知目标，一侧有远锚点；同时测第一跳、完整代理、实际移动和任务后重规划，不只测C。将固定公开输入的排序检查与同世界执行结果分开。
C. 重合任务：当前位置、多个目标、多个锚点完全重合；相同key跨类型；半径全零/不等；打乱字典插入顺序。检查任务全排列守恒、确定tie、不变输入、无除零。
D. 单任务、两任务、仅anchors、仅targets、共线/反序、首点换成不同半径目标；独立全量重算所有反转与relocate增量，重点检查首点/尾点和相邻交换。输入n<=小规模可枚举全部排列作参照，但本算法不承诺最优。
E. 空输入、NaN/inf、负半径/权重、乘积或极端坐标溢出；检查明确报错，不吞异常改状态。
F. n=41满任务规模统计实际在线CPU，且监测每次重规划的调用频率。之后由Main统一conda py314同世界对照验证全清、T/K和移动占比，并明确本地证据不是官方新演练。
