CUMCM 2026 B — 可复现研究版

官方模拟器此前并未启动的旧版说明已经过时；当前材料包含用户提供的20轮演练观察，但仍不含六次正式测试结果、正式案例表和官方加密日志，也不含参赛队人工核验记录。合成研究、官方演练观察和正式测试证据严格分层。

二、运行环境
从解压后的项目根目录执行以下Python命令；在原仓库中对应b_solution目录。统一使用conda py314：
  conda run -n py314 python --version
  conda run -n py314 python -m pip install -r requirements.txt

在线策略、HTTP客户端及合成环境使用标准库。问题一直接线性规划、独立几何验证和制图另用numpy、scipy、matplotlib；PDF检查用PyMuPDF和matplotlib依赖的Pillow。实际版本见results/environment_manifest.json。LaTeX需要XeLaTeX及latexmk，使用TeX发行版中的Fandol中文字体，无需个人机器字体。

  conda run -n py314 python run.py --problem 3 --seed 20260910
  conda run -n py314 python run.py --problem 4 --seed 20260910
  conda run -n py314 python run.py --problem 4 --scenario outward_boundary --error-mode extreme
  conda run -n py314 python run.py --problem 3 --seed 20260910 --strategy refined
  conda run -n py314 python run.py --problem 4 --seed 20260910 --strategy refined
  conda run -n py314 python experiments.py --cases 500 --output results/final_experiments.json

最后一条命令执行4430次运行：每问500个世界上baseline、batched、integrated三策略的配对比较，360次压力运行、270次敏感性运行及800次恢复消融。并非4430个独立随机世界。主随机种子600000–600499，恢复消融610000–610099，压力700000–700019，敏感性800000及900000起的30个种子。所有实验通过公开动作响应决策；总源数仅在退出后用于评价。每步虚拟时间另由实验脚本复算。

四、几何和开发对照
  conda run -n py314 python verify_geometry.py
  conda run -n py314 python intersection.py
  conda run -n py314 python second_point.py
  conda run -n py314 python compare_recovery.py

  conda run -n py314 python compare_routes.py
  conda run -n py314 python compare_probes.py
  conda run -n py314 python verify_terminal.py
  conda run -n py314 python verify_refinements.py
  conda run -n py314 python verify_coverage_limits.py

run.py与official_run.py最终默认field；显式--strategy refined保留20轮官方演练使用的原算法。两题probe_scale均为0.22，不将本轮短暂的Q3 0.12候选设为默认。两策略均采用Q3半径1200米七点环/center/unknown，Q4 compact25（原点、12个940米内环点、12个1870米外环点，错相15度）/guarded/useful。field增加有界route_portfolio路线组合：原nearest insertion控制、global cheapest插入、两个近邻初解，配合2-opt和Or-opt1，每初解不超过min(n,12)轮；localize前最多原地一次premeasure，不当独立降噪。Q3另用no_signal排除1000米盘内接16边形后取剩余区域凸外包，并在全部安全清除圆交内向当前位置靠近；Q4禁止负圆盘推断且approach_clear=False。固定最多6测加至多1预测、有限恢复及rectangle光学后备保留。fast25仅为内部负候选，已移除临时--coverage-policy CLI，不建议为它耗用官方机会。--strategy enhanced保留旧Q4 31点格点对照；历史文件、名称与分母不回写。

enhancements.py保存策略、问题、场景和误差模式下的逐世界结果；make_enhancement_assets.py重算分母、成本分解、配对差值及图表。ring_sweep.py使用开发种子1000000–1000149和新确认种子2300000–2300499，保存全部逐世界结果、差值、均值区间和全清计数，结果仅排除现实运行耗时。早期复用1100000组的比较不充当最终新样本证据。verify_coverage_limits.py检验31点见证及Q4外向圆周下界；verify_refinements.py核验环覆盖、全部720种骨架顺序、圆域内格点六邻点和测向区间上界。

verify_geometry生成历史增强配置的保守动作规模上界operation_bound.json。report/bound_proof.tex另外说明该界如何覆盖refined：25点骨架仍满足旧31点的范数与数量上界，联合调度只重排任务，已知频道筛选减少补测，固定测向与rectangle光学后备保持不变；不把它称为新策略的紧上界。intersection不添加人工包围框，分别演示原始测向半平面交的有界、无界和不可行情形。second_point是归一化候选评分示例，不是官方数据。compare_recovery使用500000–500099作为早期开发种子，develop_anchors使用1000000–1000149作为增强选择期种子；二者不能替代最终样本外比较。

五、新候选、冻结研究与独立核验
按以下顺序执行；重放开发脚本仅复现已冻结的比较，不据此或据holdout重新调整默认参数：
  conda run -n py314 python verify_research.py
  conda run -n py314 python refinement_study.py --cases 150 --seed 3100000
  conda run -n py314 python research_experiments.py

refinement_development.json：3100000–3100149，每问150世界，Q3六配置/Q4十一配置，共2550次开发运行，不能与样本外组混合分母。
research_experiments.json共10700次运行：
  主比较4100000–4100999，每问1000世界，Q3三配置/Q4四配置，共7000次；
  压力4200000–4200049，3场景×3误差×2策略×2题，共1800次；
  随机场景额外误差4210000–4210199，2误差×2策略×2题，共1600次；
  敏感性4300000–4300049，3个probe_scale×2题，共300次。
10700是策略执行次数，不是独立随机世界数。指标是逐世界T/N后取均值，配对节省为control减refined。Q4 clustered/extreme的50对平均节省为-8.1352秒/源，近似95%区间[-57.6128,41.3424]，只有25/50对更快；保留这一压力负结果，不宣称所有场景或实例都更优。极坐标、联合调度和光学候选的notes只是推导，结论以实际结果及独立核验JSON为准。默认未采用slabs光学候选。
用户提供的20轮官方演练离线分析位于results/official_practice_analysis.json，由canonical脚本official_analysis.py读取manifest和60个脱敏原始文件计算。20轮全部逐动作成本由request→response按微秒独立复算；StrictReplay仅8/20完整匹配，其他在坐标/排序分岔处停止，不造反馈、不报告未观测路线的收益。N、源类型、case标签仅为退出后离线评价；不能作为在线策略输入。Q3/Q4每轮等权均值237.9983/531.1776秒/源，pooled口径235.8227/519.3757秒/源，各139/138源全清，不混淆两种均值。不是正式成绩。

八、匿名打包与完整复现
打包只收集源码/结果白名单及manifest明确指定的60个脱敏演练文件，不含原始赛题、个人路径、账户信息、未脱敏private_requests.raw.jsonl、正式加密数据或模拟器。practice_data/内保留manifest相对路径，逐个检查robot_id==TEAM_REDACTED与源路径范围；后验标签仅限离线分析。包内MANIFEST.json记录每个文件SHA-256。完成计算、审查、制图、编译及逐页检查后执行：
  conda run -n py314 python package.py --verify
命令先检查五份metadata输入哈希、演练源哈希和PDF审计哈希；在临时解压目录移除PYTHONPATH，执行package.py中完整命令表（保留旧命令并新增官方分析、field核验/开发/确认/资产），不借用仓库源码。严格重跑4430+3080+2200+2550+10700+2250+9400=34610次核心执行，记录各数据集实际行数。fast_vs_compact_410.py的2000次辅助筛选另存，不混核心数。official_analysis.py --handoff practice_data从真实脱敏原文件重建20轮分析并完整比较，不重生源文件；初末核对61份演练输入及源码哈希。完整JSON只排除本地real_duration_s/max_real_duration_s/max_real_s，其他行为和汇总均需相同；官方实际时间观测不排除。随后重建全部图表、编译两份PDF，初末核验资产input_sha256。任何命令失败均传播，不抽样替代。每命令1800秒超时只是本地限制，不是官方预算。delivery/复现验证.json绑定当前ZIP哈希，旧验证不能用于新ZIP。每份交付≤20MiB，保留摘要页与正文≤30页检查。输出在delivery：
  B题研究论文.pdf
  AI工具使用详情.pdf
  B题研究支撑材料.zip
  复现验证.json
  交付状态.json

只有相应验证确已完成，才能把状态记为通过。包内自动审查不是参赛队员人工审查。无须运行check_environment.py，也不需要任何个人目录中的资源。

九、以后恢复官方测试时
当前已有20轮官方演练，正式测试与人工审核未完成。official_run.py连接GUI已登录、正确题号、倒计时结束后的本机接口，不负责开GUI或选择模块。参数为--problem、--robot-id、--output-dir、可选--base-url和--strategy field/refined；默认field，无--coverage-policy。
