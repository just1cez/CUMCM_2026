二、运行环境
从解压后的项目根目录执行以下Python命令；在原仓库中对应b_solution目录。统一使用conda py314：
  conda run -n py314 python --version
  conda run -n py314 python -m pip install -r requirements.txt

在线策略、HTTP客户端及合成环境使用标准库。问题一直接线性规划、独立几何验证和制图另用numpy、scipy、matplotlib；PDF检查用PyMuPDF和matplotlib依赖的Pillow。实际版本见results/environment_manifest.json。LaTeX需要XeLaTeX及latexmk，使用TeX发行版中的Fandol中文字体，无需个人机器字体。

最终默认为refined：Q3使用1200米七点环、center联合调度、unknown扫描；Q4使用compact25（原点、12个940米内环点和12个1870米外环点，外环错相15度）、guarded联合调度和useful扫描。最终策略每次重排骨架与已知目标的共同任务路线，不再独立调用旧的骨架排序分支。均保留固定测向和rectangle光学后备。显式--strategy enhanced保留历史Q3七点/Q4间距990米31点构造，Q4滚动2-opt、separate调度、all扫描。3080次增强主比较和压力运行独立记录在enhancement_experiments.json；4430次基础运行另存，不混合分母。ring_sweep.py复用150个开发世界比较8个半径，再以500个全新世界确认两个冻结半径，共2200次执行（非2200个独立世界）。

enhancements.py保存策略、问题、场景和误差模式下的逐世界结果；make_enhancement_assets.py重算分母、成本分解、配对差值及图表。ring_sweep.py使用开发种子1000000–1000149和新确认种子2300000–2300499，保存全部逐世界结果、差值、均值区间和全清计数，结果仅排除现实运行耗时。早期复用1100000组的比较不充当最终新样本证据。verify_coverage_limits.py检验31点见证及Q4外向圆周下界；verify_refinements.py核验环覆盖、全部720种骨架顺序、圆域内格点六邻点和测向区间上界。

verify_geometry生成历史增强配置的保守动作规模上界operation_bound.json。report/bound_proof.tex另外说明该界如何覆盖refined：25点骨架仍满足旧31点的范数与数量上界，联合调度只重排任务，已知频道筛选减少补测，固定测向与rectangle光学后备保持不变；不把它称为新策略的紧上界。intersection不添加人工包围框，分别演示原始测向半平面交的有界、无界和不可行情形。second_point是归一化候选评分示例，不是官方数据。compare_recovery使用500000–500099作为早期开发种子，develop_anchors使用1000000–1000149作为增强选择期种子；二者不能替代最终样本外比较。

五、新候选、冻结研究与独立核验
按以下顺序执行；重放开发脚本仅复现已冻结的比较，不据此或据holdout重新调整默认参数：
  conda run -n py314 python verify_research.py
  conda run -n py314 python refinement_study.py --cases 150 --seed 3100000
  conda run -n py314 python research_experiments.py

refinement_development.json：3100000–3100149，每问150世界，Q3六配置/Q4十一配置，共2550次开发运行，不能与样本外组混合分母。
research_experiments.json共10700次运行：
  主比较4100000–4100999，每问1000世界，Q3三配置/Q4四配置，共7000次；
  压力4200000–4200049，3场景×3误差×2策略×2题，共1800次；
  随机场景额外误差4210000–4210199，2误差×2策略×2题，共1600次；
  敏感性4300000–4300049，3个probe_scale×2题，共300次。
10700是策略执行次数，不是独立随机世界数。指标是逐世界T/N后取均值，配对节省为control减refined。Q4 clustered/extreme的50对平均节省为-8.1352秒/源，近似95%区间[-57.6128,41.3424]，只有25/50对更快；保留这一压力负结果，不宣称所有场景或实例都更优。极坐标、联合调度和光学候选的notes只是推导，结论以实际结果及独立核验JSON为准。默认未采用slabs光学候选。

八、匿名打包与完整复现
打包只收集白名单文件，不含原始赛题、个人路径、账户信息、临时文件或官方私有日志。包内MANIFEST.json记录每个文件的SHA-256。完成上面的计算、审查、制图、编译及逐页检查后执行：
  conda run -n py314 python package.py --verify
命令先检查三个metadata输入哈希和PDF审计哈希，然后解压到临时目录，重跑几何、问题一、问题二、4430次基础、3080次增强、2200次环筛选、2550次独立开发和10700次冻结研究，以及终端、候选和研究独立核验，重建全部图表并编译论文及AI详情。五组实验合计22960次运行（不是世界数；其他几何、候选检查和轨迹重放不混入这五组分母），验证文件逐组保存实际重放行数。JSON仅排除真实墙钟real_duration_s及其派生最大值max_real_duration_s；所有行为行及其他汇总字段须完全相同，不得抽样替代或吞掉错误。每条解压复现命令超时上限1800秒；这只是本地复现进程限制，不是官方时间预算。复现验证.json位于delivery，关联该ZIP的哈希；不能将上次生成的验证文件用于新ZIP。每份交付不超过20MiB，保留匿名、摘要页和正文不超过30页检查。输出在delivery：
  B题研究论文.pdf
  AI工具使用详情.pdf
  B题研究支撑材料.zip
  复现验证.json
  交付状态.json

只有相应验证确已完成，才能把状态记为通过。包内自动审查不是参赛队员人工审查。无须运行check_environment.py，也不需要任何个人目录中的资源。
