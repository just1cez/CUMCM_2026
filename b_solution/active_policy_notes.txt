ACTIVE SECOND-MEASUREMENT RESEARCH CANDIDATE — EVALUATED, NOT ADOPTED

Scope and status
The interval-scored adaptive candidate was evaluated against the fixed policy on 200 paired synthetic worlds per problem after integration. It is retained for reproducibility and methodological comparison, not used by the default planner. It reduced Q4 failed-clear attempts but increased total time; all current numeric evidence remains synthetic, not official.
Measured evidence is stored in results/adaptive_candidate_comparison.json; see the paper's strategy-screening subsection for the comparison and the reasons the simple fixed policy remains the default.

Interface
Run/import from b_solution in the same standalone-root style as planner.py: from active_policy_candidate import choose_probe, score_probes. Dependencies are geometry.py and second_point.py, plus the standard library; no simulator, client, truth, RNG, filesystem or network access.

choose_probe(polygon, readings, current_position, problem, **options) -> Point | None
score_probes(polygon, readings, current_position, problem, **options) -> list[dict]

polygon is the ordered convex conservative Track.polygon for ONE channel. readings is that channel's positive (station_tuple, public_svd_deg) history, not raw response dictionaries and never no_signal entries. Inputs are copied, not mutated. The current position and readings may come only from accepted public actions. rejected_points contains previous failed probing/clearing coordinates to avoid repetition; it does not constrain the polygon.

Options: probes_remaining=1, rejected_points=(), bearing_bins=72, error_deg=geometry.BEARING_ERROR_DEG (1.005 degrees), probe_scale=0.22, movement_weight=0.15, loss_weight=1.0, include_lens=True. Weights and discretization are development choices, not fitted or validated constants. A supplied larger error bound must agree with the caller's observation model. This policy cannot repair an already nonconservative input polygon. An empty polygon raises via enclosing_circle; it is not replaced with an initial region. No history, exhausted budget, an already optically-certifiable MEC, or no eligible candidate returns None (through an empty/no-eligible score table).

Trace rows include candidate label, point, eligibility/rejection reason; eligible rows additionally include prior MEC radius, positive-bearing radius upper bound, movement distance, geometric no-signal risk index, each dimensionless score term, total score, worst radius including an uninformative no_signal, bin count, nonempty bin count, bearing error and sample count. Selection minimizes (score, movement_m) with stable generation-order ties. score_probes and choose_probe with identical inputs generate the same ranking. To avoid scoring twice, Main can select the minimum eligible row directly when storing the trace; no mutable trace-output argument is used.

Finite candidate design and legality
Compute the current polygon MEC (c,R), with axis u from the latest positive station s to c and normal n. If this vector degenerates, the latest public bearing defines u. Candidate points are c, s, c +/- d*u and c +/- d*n with d=min(120,max(25,probe_scale*R)), plus the existing 42 deterministic Q2 lens points generated by second_point.safe_candidates using that same station/bearing/error. The original two unfailed normal-flank choices are included. This is a finite geometry-informed candidate set, not a search of all legal coordinates; the circle itself has no intrinsic preferred axis.

The station row is normally rejected because it is already in the positive history. Repeating a location does not produce independent information under the project's deterministic spatial noise models. Candidates within 0.5 m of any positive station or rejected point are excluded. Coordinate legality is the public protocol's finite +/-2,000,000 m coordinate box, not the radius-1800 source disk. In particular, valid exterior waypoints must not be projected into the source arena. Exact duplicate points are removed stably.

Interval justification for positive-bearing scoring
Let P be the current polygon and alpha the conservative bearing half-error. Partition the full readout circle into B equal angular bins centered at theta_j with half-width h=180/B degrees. For every actual readout theta, at least one j has circular distance |theta-theta_j| <= h. Its posterior wedge W(q,theta,alpha) is contained in W(q,theta_j,alpha+h). This handles wraparound automatically with sine/cosine normals. Require alpha+h<90 degrees so these wider forward wedges remain convex.

For each bin, form U_j=P intersect W(q,theta_j,alpha+h), using the existing geometry._clip_halfplane implementation, WITHOUT the 1500 m projected range cap. Omitting the cap is essential: rotating a fixed projected cap with the bin center could otherwise exclude points in the actual conservative post-reading polygon. The scoring module also omits any no_signal or directional-orientation clipping.

An axis-aligned bounding rectangle of U_j has a circumscribed disk radius b_j = 0.5*hypot(x_max-x_min,y_max-y_min), outward padded. Because both that disk and the prior MEC enclose U_j, rad_MEC(U_j) <= min(R,b_j). Thus the computable bound is
    U(q) = max over nonempty bins j of min(R,b_j).
Every possible positive-bearing posterior MEC is bounded above by U(q), in the exact geometric model. This is a continuous-readout interval bound, NOT a few sampled source locations/error endpoints masquerading as a continuous worst case. A near response triggers existing successful clearing logic, not a posterior-circle prediction. An unexpectedly wholly empty bin partition is conservatively assigned R, not zero.

Floating-point scope: geometry.clip_bearing already pads its halfplanes. A narrow wedge padded by epsilon is an exact wedge with apex translated backward epsilon/sin(alpha). The scoring widened-wedge pad is 4*geometry._padding(scale)/sin(alpha), covering that translation with numerical margin; its scale includes the same polygon/query coordinates and MAX_RADIO_RADIUS as clip_bearing. Bounding radii use outward padding and nextafter. This follows the repository's guarded floating-point convention; it is not a machine-checked interval-arithmetic proof. Main must independently check boundary containment and score-bound domination. Score radii never authorize clearing, so numerical looseness/error in ranking cannot weaken the clearing certificate if the integration invariants below are retained.

No-signal risk index and decision objective
For deterministic sample hypotheses X = unique polygon vertices plus c, define
    L(x)=max(1000, max_i ||s_i-x||).
Every actual positive station implies the unknown source radio range is at least its distance from the source. If ||q-x||>L(x), assign risk 1: a feasible low range can lose reception. This is uncertainty about reception, not certainty of failure; the true radius may be larger. Otherwise Q3 risk is 0. In Q4, use
    delta(x)=angle(s_latest-x, q-x), risk(x)=delta(x)/pi.
Degenerate vectors receive risk 1 conservatively for ranking. The final risk rho(q) is the equal-weight mean of these sample risks.

The angular term has a limited decision-theoretic interpretation: at a fixed hypothetical source x, assume a directional half-disk normal uniformly distributed over the semicircle consistent with the latest positive station and ignore other stations' orientation information. The fraction of those normals excluding q is delta/pi. No such orientation prior is specified by the contest; the channel might be omnidirectional, multiple positive stations may tighten the normal set, and polygon vertices plus center are not a posterior spatial distribution. Therefore rho is explicitly a geometric risk index, not an identified probability, confidence bound, or worst-case signal guarantee. In particular, risk 0 at finitely many sample hypotheses does not certify reception throughout P. Q2 lens points ensure range properties only under their Q2 assumptions; they do not ensure directional Q4 reception.

The dimensionless objective is
    J(q)=U(q)/R + movement_weight*||q-current||/1000 + loss_weight*rho(q).
This combines an interval worst-positive-observation uncertainty bound, actual movement cost proxy, and a declared heuristic penalty for a possibly wasted measurement. Movement at the project's 5 m/s could equivalently be expressed as elapsed travel time; the 5 s same-channel measurement cost is constant across candidates, so omitting it does not affect their ranking. There is no claimed Bellman optimality, calibrated expected total completion time, guaranteed contraction, or global optimality. The table reports R separately as the worst radius when no_signal is allowed and uninformative: the robust all-outcome bound generally cannot be smaller than R. An improvement in J alone is not evidence of end-to-end improvement.

Required integration and exact safety/completeness invariants
1. Keep the existing early certified-clear and small-radius optical logic before selection. The candidate may replace the unfailed fixed-flank selection for a known channel; it must not replace discovery, waypoint generation or bearing update logic.
2. Debit every selected candidate measurement from the SAME existing finite localizer budget (currently six), including no_signal and near attempts. probes_remaining is advisory input to a pure function, not a self-enforcing counter. Never reset the counter by re-entering localize. The initial research experiment should try one candidate second measurement, then return to the original bounded localizer using the residual budget; broader repeated adaptation is a separately labeled ablation.
3. Execute only via the existing Planner.measure and its accepted-action bookkeeping. On direction, call the unchanged real clip_bearing with the actual public angle. Never install U_j, an AABB, the MEC, a sample subset or the risk model as Track.polygon. A no_signal response leaves Track.polygon exactly unchanged; rejected-point history only affects where to go next. Keep existing contradiction/error behavior and near handling.
4. On None, resume original localizer selection with its same remaining budget. On candidate no_signal, preserve its failed probe and existing bounded loss-recovery/clear behavior, then use original localizer. At the cap, degeneracy or existing fallback condition, call unchanged optical_finish/optical_cover on the ENTIRE current polygon. This pure module cannot perform fallback actions; that obligation belongs to the integration owner. Do not swallow transport errors or inconsistent observations as successful fallback.
5. Never clear because U(q)<=19.9: that is only a predicted measurement score. Only the unchanged certificate computed from the actual current conservative polygon, or an actual successful public clear response, can close a channel.
6. Maintain all original Q3 seven-waypoint and Q4 31-waypoint triangular-lattice obligations at s=990, together with their per-channel scans and legitimate post-clear skips. An optional probe is not evidence that an unvisited coverage obligation has been met. Do not alter pending, visited or scan_records merely because a probe was selected.
7. Under the existing bounded-error/model assumptions and sufficient resources, these conditions preserve the original geometric completeness proof: selection changes no feasible set or discovery obligation; finitely many extra/local replacement measurements terminate in the same whole-polygon optical cover. This does not prove success before an official wall-clock/virtual-time deadline. CPU scoring and travel can consume those resources; preserve existing deadline handling and measure the overhead.

Complexity and operational risks
For n polygon vertices, m positive readings, B angle bins and K candidates (at most 48 before deduplication), each bin uses two O(n) convex clips and an O(n) bounding rectangle, NOT another MEC solve. Scoring costs O(K*B*n + K*n*m), plus one existing MEC call (its deterministic incremental implementation has worst-case O(n^3)). Candidate freshness costs O(K*(m+f)) for f rejected points. Space is O(n+m+f+K), with bin polygons processed one at a time and only aggregate interval bounds retained. include_lens=False reduces K to at most six. Dense trace histories are the caller's storage responsibility.

The module intentionally reuses geometry._clip_halfplane and geometry._padding rather than adding a competing clipping implementation. Those are private repository-local helpers, so Main must treat a future geometry refactor as an integration dependency. No independent packaging namespace is introduced; imports match standalone root execution.

Counterexamples and limitations to retain in reporting
- A long thin polygon aligned with the query bearing can remain long after another bearing; a normal-offset point or one of the discrete lens points need not be good. Coarse angular bins/AABBs can make distinct candidate information gains indistinguishable.
- If q lies in P, unknown source locations can approach q, sweeping all bearings. Taking a bearing at the MEC center is not guaranteed to be a useful bisection. Near success is possible but cannot be assumed for the whole polygon.
- In Q4, a previous positive station can be arbitrarily close to a directional half-disk edge. An arbitrarily small lateral move can cross it for some compatible orientation. No finite positive-only geometric score guarantees the next response is positive merely because movement is short.
- A Q2 range-safe lens point can lie behind a directional source. Conversely, a vertex marked range-risk 1 may be impossible after exact radio constraints, or the actual radius may be large enough: pessimistic sample risks can reject a useful point.
- A failure region can occur in the polygon interior even if sampled vertices appear safe. Equal vertex weights depend on polygon representation; adding redundant collinear vertices can change rho without changing P. This is a ranking limitation, not a belief update.
- Lower U(q) may require a long detour and worsen T/N. Movement weights cannot encode all later optical-cover and remaining-coverage routing costs. An adversarial no_signal sequence provides no contraction; bounded fallback is essential.
- Increasing B tightens angular relaxation but need not uniformly reduce this particular AABB-based bound under a nonnested partition, and can increase real-time overhead. Finite candidates and heuristic weights rule out any continuous global-optimum claim.
